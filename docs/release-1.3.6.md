# 1.3.6 兼容性修复

- 修复额外装备栏下羽织材料不被库存查询计入的问题，恢复从羽织末槽取料。
- 修复背包移入额外装备槽后绕过羽织互斥的问题；普通背包、猪皮包与坎普斯背包双向检查通过，保留双方物品内容。
- 改善库存接口被其他 Mod 包装后的识别，未知结构安全降级；保留其他容器查询优先级。
- 冻结调用异常时恢复临时标记，避免影响后续冻结。
- 强化异常时清理执行锁，完整扣料后的属性更新可恢复，防止旧阶段重复扣料。

技能数值、配方、羽织容量及防腐比例不变。服务器和所有客户端请更新并重启游戏。
