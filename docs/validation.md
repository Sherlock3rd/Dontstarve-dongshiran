记录日期：2026-11-02。游戏版本：本地 DST build 761239。

## 已验证

- 25 个 Lua 文件编译通过；4 种语言的受限 modinfo 环境加载通过；20 项旧配置迁移、按键分发和聊天屏蔽检查通过。
- 官方 ModUploader 完成 1.3.3 更新；Steam 返回成功；本机下载的 60 个文件与上传包逐项 SHA-256 一致。
- 英文直接输入状态下，F 对蜘蛛造成 40.8 点伤害。
- 实际 X 开启卍解，冰冻冷却保持 0；Z 冻结蜘蛛且不切换变身；再次 X 解除卍解，未刷新冰冻冷却。
- 实测在独立副本中进行，原存档文件哈希未变化；技能测试完成后正常保存退出，本轮服务器没有 Lua 错误。

隔离结果保留在 `keybinding-1.3.3-isolated-results.json`；其中 `real_engine_1_3_3_tested=false` 表示该隔离记录生成时尚未实机测试。后续实机结果另见 `keybinding-1.3.3-live-report.txt`，不要把两次验证混成一个测试。

## 限制与已知问题

- 未取得原开发仓库，无法核实其 UT 总行/分支覆盖率。`CREDITS.txt` 中的历史测试说明为发布包原有内容，本仓库导入不代表重跑了那些原始测试。
- 未完成中文输入法组合输入、多客户端、跨洞穴迁移、全玩法及全动画验收；没有原版与 Mod 的 FPS/CPU 对照基线。
- 先前源码审查发现强化异常后的状态清理、冰冻包装异常恢复、羽织 UI 内部接口依赖及高密度目标下的性能待改进；1.3.3 仅处理按键问题，没有声称修复这些问题。
- 当前冰冻只查询可冻结目标并调用 AddColdness，没有对燃烧/冒烟目标调用原生灭火接口；不能作为通用范围灭火技能。
- 前一轮实机诊断脚本曾因未声明全局导致测试服务器退出。该事故来自临时脚本，非 Mod 变身错误；后续重启完成了独立技能验收。不要在游戏中运行未检查的诊断脚本。
